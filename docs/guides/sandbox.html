Octave for your spreadsheet and other programs: sandbox mode

Guide · 23 September 2026

devtools.mcpEval ('Sandbox') is a server for programs that hand Octave data from somewhere they do not control, a spreadsheet for one, and need Octave to call a function on it and do nothing else. It runs each call in a sandbox with no network, no other program, nothing writable on disk, and only the folders and packages you name. Its best-known user is LibreOffice Calc.

From LibreOffice Calc

octave-calc, published on extensions.libreoffice.org as Octave for LibreOffice Calc, lets you run GNU Octave on the cells of your sheet without leaving Calc: from a Data → Statistics with GNU Octave menu, or from a cell, with a formula such as

=OCTAVE("mean", A1:C2, 2, "omitnan")

Behind both is this server. The extension starts it for you; you never write a launch command. What you need on the machine:

  • GNU Octave 11.1.0 or later, and this package, devtools, installed in it with pkg install devtools;
  • for the Statistics menu, the statistics package, and datatypes beneath it;
  • on Linux, bwrap from the bubblewrap package and prlimit from util-linux; on macOS nothing more, the system's sandbox-exec being built in.

Its settings are the sandbox's

The extension's settings, under Tools → Options → Advanced → Open Expert Configuration, in org.octavecalc.Settings, are passed to this server unchanged. Each one sets what the sections below describe:

Calc settingServer settingWhat it decides
Folders DEVTOOLS_SANDBOX_FOLDERS the folders of your own functions a call can see
Packages DEVTOOLS_SANDBOX_PACKAGES the Octave packages loaded, and so visible
MemoryGB, 2 DEVTOOLS_SANDBOX_MEMORY gigabytes of memory a call may use above the server's own size
TmpGB, 2 DEVTOOLS_SANDBOX_TMP gigabytes of the in-memory /tmp, the only writable place
CellSeconds, 10, and AnalysisSeconds, 300 DEVTOOLS_EVAL_SECONDS how long a cell, and an analysis from the menu, may run before it is stopped

Where there is no sandbox

Cells run only in a sandbox. On a machine without one, Windows for now, or where the sandbox fails to start, no cell is evaluated and the cell says why. The Statistics menu runs with or without one, since what it runs comes from the extension and never from the document.

What the sandbox promises

Inside the Linux sandbox, a call can read the system libraries, Octave's own installation, the packages named, with every package they depend on, and the folders named, which come ahead of the packages on the load path. Nothing else:

  • no /usr/bin, so there is no shell and no program to start;
  • no rest of your home directory, Octave's history included;
  • no network;
  • nothing writable but an in-memory /tmp, emptied before every call.

Each call runs in a process of its own, starting from the same state every time, and is killed at the deadline together with anything it started. A call that crashes the interpreter comes back as an error and the server keeps serving. Memory is capped. Your home directory itself, a folder holding Octave's history, and anything under /tmp, /proc or /dev are refused as folders.

On macOS the same promises are kept by sandbox-exec, which refuses access where Linux hides it. Two are weaker there: /tmp has no size limit, macOS having no sized in-memory filesystem, and the network is shown to be unreachable rather than proven denied, an offline Mac looking the same as a denied one.

Does this machine have one?

The server always says, in _meta["io.github.pr0m1th3as.devtools/sandbox"]. The state is settled when the server starts and does not change while it runs, so it is stated in the reply to initialize; under the stateless protocol version, 2026-07-28, which has no initialize, it is in every reply instead.

StateMeaning
"active"the sandbox was built and checked from inside, and every call runs in it
"failed"the machine has the mechanism, but the sandbox did not start or did not pass its check; the server runs unconfined
"unavailable"the machine has no mechanism, Windows for one; the server runs unconfined

For the last two, _meta["io.github.pr0m1th3as.devtools/sandboxReason"] says why. This is what Calc reads to decide whether a cell may run. To see the answer for your own machine, run devtools.selftest () at the Octave prompt: it starts a sandboxed server and reports its state, with the reason where it is not active.

For developers of other programs

Nothing here is specific to Calc. Any program can start the server and speak the Model Context Protocol to it over its standard input and output. The configuration, in the form an MCP host takes it:

{
  "mcpServers": {
    "octave-sandbox": {
      "command": "octave-cli",
      "args": ["-q", "--no-init-file", "--eval", "pkg load devtools; devtools.mcpEval ('Sandbox')"],
      "env": {
        "DEVTOOLS_SANDBOX_FOLDERS": "/home/me/analysis",
        "DEVTOOLS_SANDBOX_PACKAGES": "statistics,datatypes"
      }
    }
  }
}

What a call may see is set in the environment, never in the command: folders separated by :, packages by commas and loaded in that order. The rules of the other servers apply: do not shorten the command, and name octave-cli.exe in full on Windows. A program that needs the sandbox must read the state above before it sends a call; do not give this server to a host that does not read _meta on a machine without a sandbox.

A minimal client in Python

Messages are single lines of JSON, one per line in each direction. These cells need nothing beyond Python's standard library; run them in order. Each output shown is what the cell printed when run against a sandboxed server.

Start the server, naming in its environment what the sandbox may load, and define three helpers: send writes a message, request sends one and reads the reply, and call runs one Octave function and returns its first output.

import json, os, subprocess, sys

server = subprocess.Popen (
  ["octave-cli", "-q", "--no-init-file", "--eval",
   "pkg load devtools; devtools.mcpEval ('Sandbox')"],
  stdin = subprocess.PIPE, stdout = subprocess.PIPE, text = True,
  env = dict (os.environ, DEVTOOLS_SANDBOX_PACKAGES = "statistics"))

def send (message):
  server.stdin.write (json.dumps (message) + "\n")
  server.stdin.flush ()

def request (id, method, params):
  send ({"jsonrpc": "2.0", "id": id, "method": method, "params": params})
  return json.loads (server.stdout.readline ())

def call (id, function, args):
  reply = request (id, "tools/call",
                   {"name": "octave_call",
                    "arguments": {"function": function, "args": args}})
  return reply["result"]["structuredContent"]["outputs"][0]

Complete the handshake. Its reply says whether the sandbox is real, and a program that needs one stops here unless it is:

reply = request (1, "initialize",
                 {"protocolVersion": "2025-11-25", "capabilities": {},
                  "clientInfo": {"name": "example", "version": "1.0"}})
send ({"jsonrpc": "2.0", "method": "notifications/initialized"})
meta = reply["result"].get ("_meta", {})
state = meta.get ("io.github.pr0m1th3as.devtools/sandbox")
if (state != "active"):
  sys.exit ("no sandbox here: %s" %
            meta.get ("io.github.pr0m1th3as.devtools/sandboxReason"))
print (state)
active

Plain values. A number, a text or a logical value is passed as itself. This is nchoosek (5, 2):

out = call (2, "nchoosek", [{"type": "number", "value": 5},
                            {"type": "number", "value": 2}])
print (out["cells"])
[10]

Even a single number comes back as a list of one cell; why is explained below.

A matrix is passed as a list of rows. A flat list is a column, as Octave's own jsondecode reads it, so a row vector is written [[1, 2, 3]]. A two-dimensional NumPy array's tolist () gives exactly this form, and a one-dimensional one a flat list, which arrives as a column. null stands for NaN and the text "Inf" and "-Inf" for the infinities. A list of only true and false is a logical matrix. The only empty matrix is [], which is 0-by-0. This is mean ([1 2 3; 4 5 6]):

out = call (3, "mean", [{"type": "matrix",
                         "value": [[1, 2, 3], [4, 5, 6]]}])
print (out["rows"], "by", out["cols"], out["cells"])
1 by 3 [2.5, 3.5, 4.5]

Results come back as their shape, rows and cols, and a flat list of cells, row by row. With NumPy, numpy.array (out["cells"]).reshape (out["rows"], out["cols"]) gives the array back. The shape is stated because a JSON list cannot carry it: a row, a column and an empty matrix would otherwise be indistinguishable.

Stop the server by closing its input:

server.stdin.close ()
server.wait ()

A program that makes more than one call keeps the server running and sends each call with a new id. Measured on a Linux workstation, starting it and the handshake take about a second, and each call about 40 milliseconds more than the function itself, the price of a fresh process per call.

Its tools

In every state it offers octave_call and octave_test, and never octave_eval: it runs a named function, not code. octave_call takes:

ArgumentWhat it holds
functiona function name, such as mean or geom.area
argsthe arguments in call order, each number, string, logical, matrix or range
nargouthow many outputs to return, 1 to 16, 1 when omitted
nullDatethe date serial number 0 stands for, 1899-12-30 when omitted

A range is the form a spreadsheet hands over, for a block whose cells may differ in kind. It carries its rows, its columns and its cells row by row, each with a kind, empty, number, logical, text, error, date, datetime, time or duration, and a value. A numeric range becomes a matrix with NaN for an empty cell, a text range a cell array of text, a range of dates a datetime, a range of times a duration, and a range mixing kinds a cell array. A range holding an error cell is refused. Dates and times need datatypes among the packages.

The results are in structuredContent, not in the text, which is a one-line summary. Each output comes back as its kind, class, rows, columns and cells row by row, with NaN as null, Inf and -Inf as the strings "Inf" and "-Inf", and dates as serial numbers from nullDate. What the function printed comes back beside the outputs, and an Octave error as its message and identifier. Functions that run programs or call another function by name, such as system and feval, are refused.
